# 执行计划：百度搜索资讯获取

## 目标
在百度搜索指定关键词，切换至"资讯"标签页，获取前 N 条资讯信息（标题、来源、时间、摘要）。

## 适用场景
- 搜索目标：任意关键词（如"达州安仁乡"）
- 输出要求：前 N 条资讯（默认 3 条）

## 执行步骤

### 步骤 1：打开百度搜索结果页
- 工具：`browser_navigate`
- URL：`https://www.baidu.com/s?wd={关键词}`
- 说明：直接使用搜索参数直达结果页，等待页面加载完成

### 步骤 2：定位"资讯"标签
- 工具：`browser_snapshot`
- 说明：在搜索结果页顶部导航中找到"资讯"标签，记录其 ref 标识

### 步骤 3：点击进入资讯搜索页
- 工具：`browser_click`
- 目标：步骤 2 中找到的"资讯"标签 ref
- 说明：点击后页面跳转至百度资讯搜索结果页，显示相关资讯列表及总条数

### 步骤 4：提取前 N 条资讯
- 工具：`browser_snapshot`
- 说明：抓取资讯列表内容，整理出每条资讯的：
  - 标题
  - 来源媒体
  - 发布时间
  - 内容摘要

## 关键参数
| 参数 | 说明 | 示例 |
|------|------|------|
| 关键词 | 用户提供的搜索词，必须原样使用 | 达州安仁乡 |
| 资讯条数 N | 需提取的资讯数量，默认 3 | 3 |

## 注意事项
- 关键词必须使用用户原始输入，禁止替换为占位符
- 步骤 2、3 之间若页面结构变化，需重新 snapshot 定位
- 若"资讯"标签不可见，可尝试直接在 URL 后追加 `&tn=news` 或使用百度资讯频道
- 若结果为空，检查关键词是否正确，或放宽搜索条件重试

## 意外应对
| 意外情况 | 应对策略 |
|---------|---------|
| 资讯标签找不到 | 重新 snapshot 查看页面结构，或改用资讯频道 URL 直达 |
| 搜索结果指向错误目标 | 在关键词中追加限定词（地域、类型、时间）重新搜索 |
| 页面加载超时 | 等待页面加载完成后再操作，最多重试 3 次 |
| 结果条数不足 N | 提取实际存在的全部条数并说明 |

## 输出格式
按顺序列出前 N 条资讯，每条包含：序号、标题、来源、时间、摘要。
